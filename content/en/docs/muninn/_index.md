{{% pageinfo %}}
Maven core extension producing compact JSON reports, for coding agents
{{% /pageinfo %}}

Replaces Maven console output with one compact JSON report if agent invokes Maven; the full log is still written to disk and the report points to it.

Sources: https://github.com/maveniverse/muninn
